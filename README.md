# CodeAlpha_Data_Visualization
Data visualization project completed as part of the CodeAlpha Internship using Python, Pandas, Matplotlib, and Seaborn. Analyzed a books dataset and created bar charts, count plots, histograms, box plots, and scatter plots to explore book prices, ratings, distributions, and relationships.
# CodeAlpha Task 3 – Data Visualization

## 📌 Project Overview

This project was completed as part of my **CodeAlpha Internship**. The objective of this task was to transform raw data into meaningful visualizations and identify useful patterns and relationships within the dataset.

For this project, I used a **Books Dataset** containing information about book titles, prices, ratings, and availability.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## 📊 Visualizations Created

1. **Average Book Price by Rating** – Bar Chart
2. **Number of Books by Rating** – Count Plot
3. **Distribution of Book Prices** – Histogram
4. **Book Price Variation by Rating** – Box Plot
5. **Relationship Between Book Rating and Price** – Scatter Plot

## 🔍 Analysis Performed

The project focuses on:

* Understanding the structure of the dataset
* Analyzing book prices and ratings
* Comparing average prices across ratings
* Understanding the distribution of book prices
* Identifying variations and possible outliers
* Examining the relationship between ratings and prices

## ▶️ How to Run

### 1. Clone the repository

```bash

```

### 2. Open the project folder

```bash
cd CodeAlpha_Task3_DataVisualization
```

### 3. Install required libraries

```bash
pip install pandas matplotlib seaborn
```

### 4. Run the Python file

```bash

```
